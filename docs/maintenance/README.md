# 维护与发布

公开仓库只维护源码、通用说明及公开离线测试。设备清单、来源审计、归档记录、真实地图、照片、雷达录制和标定属于内部交接资料，不在此目录分发。

- `tools/project.py check` 检查公开源码；内部地图/来源清单存在时也核对它们，但不会要求公开克隆包含这些资料。
- `python -m tools.maintenance.public_hygiene --staged` 检查实际Git暂存快照，报告路径和问题类别，不输出密钥内容；不等于全历史秘密扫描。
- `assemble_workspace.py` 等收回工具仅供配置后的内部维护使用；真实设备主机、账号和SSH主机密钥指纹通过环境配置，不硬编码。
- 不要整目录覆盖设备。按明确文件清单发布，先确认任务空闲、备份，并保留设备学习状态、地图、标定和私密配置。
- 公开清理版没有部署到设备，不改变当前小车的电机、相机或机械臂状态。

见[公开范围和历史限制](../publication.md)。如果需要移除旧历史内容，应先协调所有协作者、分支及标签，另行授权历史重写；不能把一次普通删除提交说成已经彻底清除。
