# 公开范围与隐私清理

2026-10-16 起将公开源码和内部实机交接资料分开。

公开保留：功能源码、通用协议与算法、Android/固件、仿真、空配置模板、通用测试和使用说明。

内部保存、不再包含在清理版文件树中：

- 实际场景雷达录制回放、与现场地图绑定的玻璃边界。
- 真实设备标定与机械臂模型元数据、模型权重。
- 机器来源清单、完整DeepSeek扫描路径索引、电脑归档记录、具体部署审计。
- 真实服务器地址、设备MAC、个人家目录和SSH主机指纹（源码改为示例或显式外部配置）。

移出前已在仓库外保留完整内部备份，未永久删除原资料；本次不接触设备，也不清空用户的实际API密钥。后续公开部署必须自行提供内部配置，不能把示例当成现用参数。

## 已公开历史仍然存在

这是普通清理提交，**不清除旧提交、旧分支、旧压缩包、分叉、他人克隆、拉取请求缓存或搜索缓存**。原交接版本已经公开过，不能保证回收已有副本。

如果这些资料需要从历史中移除，需仓库管理员单独授权并协调全体成员，备份后重写涉及的历史、清理分支/标签，必要时联系托管平台处理缓存。不要未经确认强推。密钥泄露应优先在供应商账户撤销；删历史不能替代撤销密钥。

## 验证边界

公开检查覆盖源码和通用离线测试。内部地图和录制数据缺失时，专用回放显式跳过；只有恢复内部依赖后才能进行完整实机验收。新增公开内容提交前运行：

```bash
python tools/project.py check
```
