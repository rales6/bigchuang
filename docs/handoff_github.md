# 部署准备

部署前先阅读[根 README](../README.md)、[功能索引](features.md)、[组件边界](architecture.md)和[依赖说明](../requirements/README.md)，确认树莓派、GPU服务器、固件与客户端的运行边界。

## 获取代码

```bash
git clone https://github.com/rales6/bigchuang.git robot-car
cd robot-car
```

默认使用 `main` 分支；开发时创建独立功能分支。

## 准备运行依赖

- 场景对应的雷达/语义地图、发布哈希与视觉定位参考。
- 与地图匹配的玻璃边界及需要使用的回放数据。
- 当前机械臂模型权重与元数据、相机标定和设备参数。
- 设备网络、访问权限与API配置。
- 当前设备的速度学习状态及需要保留的运行经验。

按[配置说明](configuration.md)放置运行数据，或指向设备上已有的发布目录。地图、模型、标定和相机顺序应配套使用；不要混用不同设备或不同批次的配置。

## 安装、验证、运行

先按README运行离线检查，再进行数据回放。缺少场景依赖时，相关用例会明确标记跳过；补齐依赖后再安排实机验收。

文档、脚本中的网络和家目录均为示例，运行部署工具前需替换为自己的配置。相机顺序、舵机标定、模型和玻璃包络以设备验证结果为准。实际动作需安排现场看护和急停。

运行与发布步骤见[维护文档](maintenance/README.md)。
