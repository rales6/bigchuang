# 小车助手 Android App

一个独立的原生 Android 项目，用类微信的对话方式向树莓派发送任务指令，并展示树莓派返回的消息、摄像头画面与任务进度。

## 已实现功能

- 对话页：文字输入；语音模式为微信式“按住说话、松开发送、滑开取消”，聊天里显示语音指令气泡和时长，不把识别文字直接填入输入框。
- 监控页：显示树莓派的 MJPEG 实时视频、连接状态、视觉/雷达/避障状态和急停按钮。
- 任务页：概览、地图、步骤三个紧凑视图，展示规划步骤、实时状态、当前判断和任务点地图。
- 设置页：包含小车配置（建图、标注、蓝牙、音量）以及树莓派连接、TTS、方言、通知和免打扰。
- 成人模式：全部功能。
- 少儿模式：隐藏实时监控和高级设置，拦截运动/机械臂类控制词；退出必须验证 6 位监护密码。密码使用 PBKDF2-HMAC-SHA256、随机盐和 120,000 次迭代保存，不存明文。
- 老人模式：隐藏复杂监控页，默认语音输入和自动朗读，聊天/任务页使用更大的文字和按钮。
- 导航始终只有底部四项：对话、监控、任务、设置；监控和任务优先在一屏显示，设置的详细参数页在必要时局部滚动。
- 本地保存最近 100 条聊天消息和全部设置。

## 页面结构

```text
手机
├─ 对话：文字 / 按住说话 → 树莓派
├─ 监控：MJPEG 视频 + 运行状态（成人模式）
├─ 任务：概览 / 地图 / 步骤 + 急停
└─ 设置：连接、小车配置（成人模式）、语音、模式、通知
```

## 首次使用

1. 手机与树莓派连接同一个可信 Wi-Fi。
2. 在树莓派项目运行 `./companion_service.sh`，默认监听 `8770` 端口。
3. 打开“设置 → 树莓派连接”，填写例如 `http://172.18.14.74:8770`，保存并测试。
4. 视频服务若使用同一地址的 `/stream.mjpg`，视频地址留空即可；也可单独填写原监控服务地址。
5. 允许麦克风权限后，在对话页点麦克风切换到按住说话模式；Android 13 及以上允许通知权限后才能收到系统通知。
6. 进入少儿模式前先在成人模式设置 6 位监护密码。

完整 JSON 字段约定见 [docs/raspberry-pi-api.md](docs/raspberry-pi-api.md)。

## 语音和方言说明

语音识别与朗读使用 Android 系统的 `SpeechRecognizer` 和 `TextToSpeech`，不会在 App 内捆绑大型语音模型。普通话通常开箱可用；粤语、台湾国语或英语取决于手机厂商及已安装的 TTS 语音包。如果选择的语音不可用，App 自动回退到普通话。

当前树莓派任务接口只接收文字指令，因此 App 在松开语音键后于后台识别并发送指令文本；聊天界面只显示“语音指令”和时长，不展示识别文字，也不保存可回放的录音文件。语音识别结果仍经过少儿模式安全规则检查。

## 当前边界

- 树莓派桥接服务只允许预定义的建图、标注和寻物入口，配置经过范围与路径检查，不接受手机传入任意命令。
- 轮询和视频在 App 前台运行。若后续需要锁屏持续接收，应由树莓派提供推送通道，并增加 Android 前台服务。
- 当前为可信局域网 HTTP 对接。跨公网发布前应增加 HTTPS、设备鉴权和密钥轮换。
