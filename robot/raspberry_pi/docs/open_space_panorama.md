# 开阔点全景巡检

在 `map_camera_inspection` 中增加 `--open-space-panorama` 可启用新模式。
`inspect_map.sh` 已选择该模式；删除这一开关即可回到原来的固定目标巡检。

新模式继续读取 `maps/ble_scene_17.pgm/.yaml`，不生成固定拍摄机位、不调用 A*，
不建立或累积临时占据地图，也不会写入原来的永久语义实体文件。
启动时仍复用已知地图初始定位；之后按当前雷达和旧地图短距离安全边界选择粗略方向。

## 默认行为

- 雷达帧间里程计每帧更新位置，`live_pose.json` 每帧原子替换；控制台约每 0.2 秒输出。
- 当前 ESP32 客户端没有编码器里程计反馈接口，因此使用雷达帧间里程计；不把指令时长当实测位移。
- 地图预览 `inspection_plan.png` 约每 0.5 秒刷新位置、车头、轨迹和拍摄站点。
- 累计行驶 1.2 m、拍完全景或局部地图安全边界无方向时，才采集地图纠错候选。
- 纠错只搜索当前位置附近 0.65 m，至少两个连续候选一致，融合比例为 20%。
- 开阔位置最小四向净空 0.48 m，至少三个方向净空超过 0.72 m。
- 站点与所有已有站点相隔至少 1.0 m；理想间距 1.6 m，超过 2.5 m 只短退一次。
- 无理想站点时允许安全的次优位置，避免反复后退或无限寻找。
- 每站点按 60° 步长拍六个方向，并用实测相对旋转累计量记录方向。
- 单帧转向里程计无效时先停车，再用同一参考扫描重测；不能恢复则结束本次旋转。
- 连续无效帧继续保留上一可信扫描参考，停车恢复后才允许再次运动，避免漏记整段转角。
- 每张照片前采集停车后的扫描，积分停车尾段，再记录实际朝向。
- 避障短转向使用 0.30 m 四向净空门槛，拍摄站点仍要求 0.48 m；每帧重查，遇近回波立即停车复核。
- 前进/倒退检查车身宽度内的雷达通道，并包含雷达的安装偏移，不只检查车头中心射线。
- 后退脉冲最多 0.6 秒/约 0.12 m 实测位移，持续扫描；允许延迟启动，不在第一帧无位移时立刻取消。
- 部分全景失败的位置不会原地反复重拍，已拍照片仍保留。
- 每次拍摄尝试独立编号，未完成站点不会覆盖已有照片。
- 几何覆盖目标为 90%，停止阈值加 2% 位姿/视场误差余量（默认估计覆盖 92%），至少三个完整站点。
- 最多 16 个站点和运行时间上限仅作为兜底；未覆盖清单总会保存。
- 连续 30 个控制决策没有有效运动时停止并保存部分结果，不假报覆盖充分。
- 所有运动结束并停车之后，才按顺序调用 Qwen。

## 输出文件

- `inspection_manifest.json/.csv`：照片坐标、绝对方向、相对旋转角、站点号、
  拍摄时间、定位置信度和雷达净空。
- `live_pose.json`：当前实时状态、位姿、最近可信地图位姿、覆盖率和距离。
- `panorama_navigation.jsonl`：逐帧运行状态。
- `inspection_plan.png`：旧地图上的实时位置、方向、轨迹和站点。
- `panorama_coverage.json`：几何覆盖率及未覆盖边界采样位置。
- `panorama_semantics.json`：停车后的 Qwen 观察；不确定项保留为可疑/未确认。
- `panorama_summary.json`：站点数、照片数、最终覆盖率与结束位姿。

全景照片并不具备可靠深度，不能把一个画面中的某个标签直接扩散到整块黑色连通体。
因此新模式不覆盖已有永久语义地图；识别先保存在本次独立旁车文件。
几何覆盖率表示旧图边界进入过相机视场，不等于模型一定正确识别了所有物品，
也不能保证被遮挡、高处或雷达不可见物体全部被看见。

## 仿真

直接执行正式状态机的验收入口：

```powershell
python -m car_sim.open_space_panorama_runtime_stress --profile realistic --seed-count 5 --output simulation_runs/open_space_panorama_runtime.json
```

此入口替换硬件、时间和扫描匹配观测模型，执行正式树莓派控制/保存代码。
下方脚本是独立高层压力模型，只作为诊断补充，不能代替正式状态机验收。
两者都使用合成的有界扫描里程计，不是实际 ICP 或 Qwen 识别准确率验证。
正式状态机仿真的合成观测现在返回真实 `MatchResult` 类型，不再额外伪造
`translation_m` 字段；位移统一从 `transform.x_m/y_m` 计算。单元测试另行执行
真实 `ScanMapLocalizer.relative_motion` 和 ICP，以检查静止、移动扫描的接口。
这些检查仍不能代替真实雷达日志回放与现场验收。
车体假设为约 0.20 m 安全半径；实车尺寸、相机视场和转向响应仍须现场确认。
部署时还需要同步 3090 的新全景提示词并重启推理服务；本次本地修改不会自动部署。

```powershell
python -m car_sim.open_space_panorama_stress `
  --profile realistic `
  --seed-count 20 `
  --output car_sim/output/open_space_panorama_realistic_20.json
```

仿真复用旧图、真实场景边缘扰动、四轮差异、静摩擦、打滑、低电压、指令延迟、
玻璃穿透和雷达噪声。车辆只选局部方向，不给定拍摄目标或完整路线。
验收要求每个种子真实边界照片覆盖率不低于 90%、零碰撞、无长时间静止指令，
并拒绝注入的远处对称位姿候选。
