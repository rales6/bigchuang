# 联合建图与视点标注（验证版）

**当前状态（2026-09-05）：未通过全程闭环验收，未部署；不要当作实车稳定版运行。**

最新两组真实控制器 + SLAM 合成雷达闭环均到 900 秒仍未报告探索完成，分别行驶约 49.98 / 49.13 m，最大定位误差约 5.11 / 6.99 cm，最大朝向误差约 11.45 / 11.47 度。没有模拟碰撞不代表实车安全；剩余的重复补扫和任务收尾尚未解决。结果在 `simulation_runs/joint_mapping_validation_summary.json`，完整轨迹在 `joint_closed_loop_view_fix_seed0/1/report.json`。

本轮共 266 项相关回归测试通过，另有 5 组桌子上方指定路线的真实 SLAM 雷达回放通过。上述测试不能替代全程闭环验收。旧图缺失通道、玻璃、滚动扫描的完整扰动模型仍未验证；也没有这次现场原始扫描用于精确重现定位错误。

本入口不再先把车匹配到旧地图再开始拍照。SLAM、现场探索、照片位姿都在本次启动的局部坐标系内。原点是首个有效扫描，+x 为启动时车头方向，不是旧图向右。用户描述的“桌子左上、车头朝下”是复现线索，尚不足以生成准确的旧图坐标变换。

旧 PGM/YAML 原样复制到新运行目录的 `coarse_reference`，带 SHA256；**当前仅作未配准参考，不参与定位或规划**。尚未实现自动可靠配准、用旧图引导补扫，不能称为完整的粗到细建图算法。旧地图、旧标注与 `inspect_map.sh` 不变。

## 运行与输出

仿真验收通过并部署后才使用 `bash map_and_annotate.sh`。不要与 `easy_start.sh` 或其他运动任务同时运行。本脚本只与原巡检入口共享锁，不能阻止其他不使用该锁的程序。

输出在独立的 `mapping_sessions/<时间_随机编号>/`：

- `map.pgm/yaml/png`：新地图和坐标元数据；不会覆盖旧图。
- `photo_viewpoints.png`：蓝点为相机位置，蓝线为车头方向，编号对应观察记录，不代表物体位置。相机必须实际朝车头安装，尚无视觉外参校准保证。
- `view_*.jpg` 与 `observations.json`：停车融合时的扫描时间、估计位姿、拍摄时间、相机信息及 Qwen 原始识别。无可靠深度的类别只作为视点证据，不扩散到整面墙，不自动成为导航目标。
- `scans.jsonl.gz`：所有进入 SLAM 的完整扫描（含拒绝帧）、位姿、上一运动命令；后续可用真实雷达回放诊断，不再只看最终地图。
- `config.json`：运行参数。

默认约 0.65 m / 55° 视点去重，至少间隔 8 s。只在停车融合后拍摄，拍照后丢弃旧雷达生成器并重新收集稳定帧；不依据拍照前的旧扫描立即前进。3090 请求在单独线程中执行，队列最多两个等待项。队列满、断网、退出时未完成的照片均保留为 `deferred_inference`，不伪报“全部标注完成”。

停止运动后可仅补推理（此命令不创建运动客户端）：

```bash
python -m raspberry_pi.joint_mapping --resume-annotations mapping_sessions/<运行目录>
```

## 验证范围

```bash
python -m unittest tests.test_joint_mapping tests.test_autonomous_mapping tests.test_pi_mapping
python -m car_sim.joint_mapping_replay --seeds 5
python -m car_sim.joint_mapping_closed_loop --steps 1800
```

回放使用用户原 PGM 生成雷达，路线为近似的桌子上方通道，执行真实 `LidarSlam`；不含真值位姿输入。闭环仿真另外运行真实建图主循环、规划器、速度控制器，以合成雷达驱动。两者都不等价于实车：未校准实际轮速、完整模拟玻璃反射、滚动扫描畸变、地毯摩擦及通信时延。不能仅凭测试通过承诺不跑偏、不碰撞。

建图流程返回也不代表视觉覆盖完整；尚需完成物体跨视角关联、视觉盲区补拍和回环后的历史照片坐标修正。本版保留原始证据，为这些步骤提供输入。

收尾修复：原探索器在没有任何可达新路径时，仍会因为新观察到 0.02 平方米的边缘像素而重置收尾扫描角度。现在保留整圈扫描进度；一旦真正发现可达路径，仍立即取消完成判定并继续探索。不是按超时强制宣布成功。

补扫方向修复：遮挡区的普通补扫点现在附带可见未知栅格的观察方向，到位后先朝向该方向。仅仅位置到达、但朝向不符时的停车融合不再提前清除观察任务；未知区补扫也不冒充已确认的物体侧面观察次数。
