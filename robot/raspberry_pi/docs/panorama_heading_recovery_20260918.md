# 转向丢失后的朝向恢复与短时路线测试

本次在上一版“正常选向和障碍脱困分开、异常雷达停车复查”的电脑源码上增加独立朝向修复。初始定位、原占据地图和任务入口/启动脚本不修改；扫描运动质量门槛、防撞、后方未知不倒车规则保留。

## 原因

`20260918_191531` 第一张照片用户观察位置基本正确，之后逐渐偏移。19:16:22 和 19:17:21 转向运动因 `turn_translation_unverified` 被拒绝，原实现随后保留旧位姿却换新参考扫描继续运动。未测准的真实转角可能因此丢失，后续位移沿错误朝向累积。三次朝向纠错与六次地图候选确认均因质量不足未融合。

第三站计划 60° 的照片实际记录相对角度 107.1°，存在严重过冲或角度估计问题。记录没有独立物理真值，不能将它等同于实际转角。本次不靠直接接受被拒绝结果解决。

## 修正

- 未解决的转向不再进入“丢掉参考、保留旧朝向继续走”的普通重锚分支。使用原扫描、原可信 XY 参考恢复旋转角。
- 停车后允许显式搜索较大旋转角。扫描匹配器默认 ±60° 不变；仅恢复调用显式使用 ±180°，不执行全图 XY 搜索。
- 正反旋转拟合均须 RMSE ≤8 cm、内点率 ≥70%、对应点至少 60，组合角误差 ≤3°。相隔 30° 的备选旋转若成本接近则拒绝，不把对称候选当成可信朝向。
- 候选还须通过原 XY 处的地图端点和绝对距离检查。地图端点 RMSE ≤10 cm、内点率 ≥60%；距离一致率 ≥65%、平均误差 ≤22 cm、有效覆盖 ≥60%。实际侧滑或原 XY 已错时可能不通过，不能硬恢复。
- 连续三张不同的新鲜停车扫描得到相近朝向才应用：两张确认、一张停止尾转检查。只恢复原参考处的 yaw，不写入被拒绝的平移、不累计假行驶进度。恢复后仍标记位置不确定，交由现有局部纠错确认。
- 恢复无可信结果时停车并报告 `turn_heading_unresolved`，不再把后续稳定的相对扫描误认为绝对朝向已恢复。检查最多六帧，合作式预算三秒；单次底层计算不能被抢占，可能有少量预算超时。
- 小角度转向持续输出按剩余角度、输出速率及实测角速度限时。20°/3000 mrad/s 的起步请求由固定 350 ms 改为 120 ms；保留扭矩与最低有效脉冲，不改成无法发送的短脉冲。控制延迟及真实电机速度仍会造成误差，需实车检查。

回归包含原参考恢复、不一致/低质量/重复帧不融合、生产状态机不得丢掉未确认转角后直行、小角度限时，以及旧地图射线生成的真实匹配检查。完整扰动状态机仿真仍为合成里程计，机械卡滞场景未全部通过，不代表已保证全程成功。
