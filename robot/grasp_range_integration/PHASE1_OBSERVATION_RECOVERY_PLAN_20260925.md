## 2. 建议改成的寻物状态机

```text
路过/到站观察
  ├─ 两摄均无可信候选：继续本站尚未覆盖的前向工作区角度
  ├─ 任一摄出现可信候选：记录候选和双摄原图 → 留在本站附近做小角度视觉对准
  │   ├─ 双摄匹配同一目标：停车，报告“已找到”；不夹取
  │   ├─ 单摄连续可见但另一摄仍看不到：仅在安全净空充足时小角度转向，必要时小幅横向换位
  │   └─ 候选消失或复查超时：记录“疑似误检/丢失”，继续本站其他方向
  └─ 本站所有必要方向均失败：再规划下一站；低置信区仍须用户同意
```

“一摄出现就行”用于**立即触发复查**，不再直接放弃该方向；最终“找到并可交给后续夹取”仍要求双摄同物确认和安全距离。单摄候选要至少跨相邻帧稳定、类别/颜色一致，不能只信一次 Qwen 高置信度或两路恰好相同的框坐标。若始终只有单摄证据，可报告 `seen_unconfirmed` 并保留照片，不把它等同双目测距成功。

复查先原地微调，让候选从边缘移向两摄共同视场；调整方向由**对应摄像头的候选水平位置及双摄标定**决定，而不是硬编码“左摄见到就向左转”。不确定距离时禁止朝候选前进；如确需平移，先以雷达和地图确认路径、保持工作区禁入距离，并限制单次位移及复查次数。用户不希望频繁停车，因此仅在计划站位或出现单摄候选时短暂停稳拍照，不恢复每隔固定距离的停车拍照。

## 3. 转向与视角覆盖

先用短时实测标定“命令速度/TTL → 实际转角”，分别记录左右转、启动静摩擦、停止后余转；不能把指令角速度直接当实际角速度。行驶转向与到站扫视分开：较大误差可使用能克服静摩擦的脉冲，接近目标朝向时按**实测剩余角**缩短脉冲、停车稳定后重测；发生目标角误差变号或连续两次误差不减，立即退出补偿并重新定位/规划，禁止来回加速追角。是否能可靠做到小角度转动，应由安全短转实测决定，不能预设低速一定能克服静摩擦。

观察方向不是离散“点+一个固定朝向”。第一站仍只覆盖柜子工作区进入相机有效识别距离的前向角扇区；每次按当前已覆盖像素视场补下一段未覆盖角度，不转向背后，也不预先生成全部站位。加入角度滞回和“已看过的实际视场”记录，避免超调后反向、反复扫同一片区域。航点无进展判据区分平移和原地转向：转向时记录目标角误差是否收敛，而不是只看航点距离；总转角、时间和反复次数仍有硬上限。

## 4. 观察距离与避碰

把首选高置信站位距**工作区边界**的暂定 0.55 m 提至约 0.8–1.0 m，并把底盘半径、定位误差、停车余量和可能的物块位置作为不可越过的缓冲；精确值须用双摄实拍验证，不能仅因拉远就超过目前暂定的 1.8 m 有效识别距离。以“预计可识别的工作区比例 + 最近潜在物块净空 + A* 可达 + 相机视角”共同评分，若远站位看不清再换侧向站位，而非直接朝物块直线靠近。

对地面小物块，雷达可能扫不到物体本身；因此不能单靠前向雷达判定安全。发现单摄候选后，物块可能所在方向先设临时禁入扇区，未得到双目距离前只允许满足净空的原地对准/有限侧移。原地转向也要检查车体旋转扫过的区域及周边动态障碍，不能沿用 `linear<=0` 即放行的前进障碍判断。若候选已非常近或净空不明，停车报告，不尝试“挪到双摄都看见”。

## 5. 停车照片与可审计日志

当前每次停车其实已拍左/右两张图，但重规划后的同名 `view_01.jpg` 会覆盖旧图。第一优先级是在 Phase 1 适配层保存**追加写、不覆盖**的原始双摄图：以全局递增观察序号和时间命名，如 `obs_0001_left_raw.jpg` / `obs_0001_right_raw.jpg`；兼容通用执行器原文件名，但在拍完后立即归档。每次候选复查、转向前后也各保存一对图。

同时生成带框副本和 `observations.jsonl`：记录站位/第几次重规划、拍照时间、定位及目标朝向、雷达净空、左右相机设备号、识别来源、类别/颜色/置信度、像素框、单/双摄匹配、拒绝原因和对应原图名。再生成一页缩略图索引，按“未看见 / 单摄疑似 / 双摄确认 / 感知失败”分组。原图永不画框，便于区分“相机没拍到”“拍到了但模型漏检”“模型误检”“双摄配对失败”。

## 6. 偏航问题与验证顺序

短期继续利用雷达贴图回航，但单独记录每段直行的指令航向、雷达实测航向、横向偏移及左右轮控制量；只有多段同向偏差稳定重现，才校准轮速/车体参数。不要把回航成功当作底盘没有偏航，也不要在转向控制尚未定因时同时大改直行控制器。

验收分四步，均不执行夹取：①离线重放已有 `mission.json`，核对候选状态机、重规划不覆盖照片；②静止摆放红块，验证左摄先看到时能在原站位找回双摄，保留所有原图；③有人现场急停条件下仅做有限左右短转，量化超调、停后余转及旋转净空；④短距离寻物实车，确认首站多朝向扫描、工作区缓冲、单摄复查、最终双摄停车。每步不合格即停在该步修正，不直接运行完整夹取。
