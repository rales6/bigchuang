# 文件分组说明

这个目录保留原项目结构，同时按部署角色额外整理了四个文件夹：

- `备份文件`：原代码备份压缩包。
- `3090`：放到 RTX 3090 Linux 机器上运行的推理服务端。
- `windows摄像头`：放到 Windows 摄像头机器上运行的客户端。
- `linux摄像头`：放到 Linux 摄像头机器上运行的客户端。

## 3090 Linux

```bash
cd 3090
python -m venv .venv
source .venv/bin/activate
pip install --upgrade pip
pip install -r requirements/remote.txt
python scripts/run_3090_server.py --config configs/linux_3090_remote.yaml --host 0.0.0.0 --port 8000
```

模型仍按下面路径放置：

```text
3090/models/qwen/Qwen3-VL-2B-Instruct
3090/models/yolo/yolo11n-seg.pt
```

如果不想复制大模型，也可以把 `configs/linux_3090_remote.yaml` 里的模型路径改成 3090 机器上的绝对路径。

## Windows 摄像头

```powershell
cd windows摄像头
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install --upgrade pip
pip install -r requirements\client.txt
python .\scripts\run_camera_client.py --server ws://<3090机器IP>:8000/ws --camera 0 --backend dshow --width 640 --height 480 --command "持续跟踪右侧的蓝色水杯"
```

## Linux 摄像头

```bash
cd linux摄像头
python -m venv .venv
```
