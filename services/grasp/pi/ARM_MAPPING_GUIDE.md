# 双摄目标中心到机械臂参数：采集与训练

## 采集前

1. 固定左右摄像头、车体和机械臂基座；后续不要改变相机角度。
2. 打开 `/arm-mapping`，填写唯一、稳定的物体名称。
3. 每次开机先点“归位”。如果机械臂被手工搬动过，则在一个可重复姿态点“以当前位置为零点”。
4. 状态记录的是固件命令积分值：前后 `D/U`、上下 `B/F`、左右 `L/R`、夹爪 `C`。设备没有关节编码器，因此不能读取真实舵机角度；BLE 未实际写入的命令不会进入状态。

自动抓取的进入视野序列仍是 5 次 `D20`。标定页的手动步长仅限：前后 1/2/5，上下 1/2/3，左右 1/2/3。

## 每个样本怎么采

1. 在实时双摄画面中，用细步控制把机械臂移动到确实可以夹取的位置。
2. 点“同步拍摄左右图”，冻结这一对画面。
3. 点“Qwen目标 + YOLO夹指”。青色为目标框和中心，黄色为夹爪框，红/蓝点为两个夹指。
4. 自动结果不准时，在左右画面分别点“目标中心”“左夹指”“右夹指”后直接点击修正。
5. 只有这个姿态确实可夹取时，勾选“当前姿态确实可夹取”。检查过夹指点时勾选“已人工检查夹指点”，即可同时把两幅图加入 YOLO-Pose 数据集。
6. 点“确认保存”。样本数量不设上限，每张确认图只累计一次；重复点击不会重复加入夹指数据。

应覆盖工作区的左、中、右、近、中、远、较高、较低位置，不要只在同一个点重复拍摄。最低 8 对确认样本才能训练；建议每个物体先采 30–50 对，测试误差仍大时继续采到 100 对以上。

## 中心映射如何训练

输入只包含两台摄像头的归一化目标中心 `(lx, ly, rx, ry)`、水平视差 `lx-rx`、均值和二次交叉项。水平视差会随深度变化，因此两幅二维图能够给出隐式深度信息。相机必须固定；移动相机后应重新采集。

标签是抓取位置对应的累计参数：

- `forward_mm`：前伸 D 为正、后退 U 为负；
- `up_mm`：上升 B 为正、下降 F 为负；
- `yaw_deg`：左 L 为正、右 R 为负；
- `claw_value` 会随样本记录，但不参与中心回归，夹紧值仍由抓取状态机控制。

网页使用带 L2 正则的多项式岭回归，固定 80% 训练、20% 测试，并报告三个输出的 MAE。这个模型很小，在树莓派 CPU 上可瞬间训练，不占 3090 显存。页面选择的量化步长会把预测值取整到你指定的前后/上下/左右等级。

模型输出适合作为从归位姿态出发的粗定位参数；最后几厘米仍应使用目标中心和夹指点做视觉闭环微调，再双摄确认后夹紧，不能仅凭一次回归预测直接闭爪。

## 夹指 YOLO-Pose 怎么训练

夹指点和中心映射是两套数据用途：夹指点不会进入机械臂参数回归。夹指训练数据同样不设上限，建议每台摄像头至少 50–100 张，并持续增加：

- 不同高度、左右角度、距离和光照；
- 两个夹指都清楚的图为主；
- 保留一部分只看见一个夹指的遮挡图，把不可见点设为不可见；
- 夹点顺序始终按图像左侧、图像右侧标注。

在 `/gripper-dataset` 中继续逐张检查或补标，随后执行低显存 YOLO11-Pose 训练并部署 `best.pt`。训练时 3090 会暂停 Qwen 标注请求；完成并部署后再继续采集/自动抓取。
